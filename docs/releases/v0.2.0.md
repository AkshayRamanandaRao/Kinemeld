Kinemeld 0.2.0 reorganises the workbench into **Pre-processing → Solve → Post-processing** workspaces, adds industry-inspired MBDyn studies with physics verification and an end-to-end STEP-to-results demo, and ships desktop builds for Linux, macOS and Windows.

### Highlights
- **Industry-inspired demos.** A recorded session that builds an automotive wheel-end drop test from its original STEP files through solve and post-processing, plus studies of a double-wishbone quarter-car, an oleo-pneumatic gear drop test, an aircraft nose gear, an oleo strut fixture, a wheel-end drop test and a slider-crank engine — each one click from *Examples → Featured studies* and checked against independent physics.
- **Professional workflow.** Each workspace shows only what that stage needs: model tree and properties; study settings, pre-run checks and a solver console; or animation, interactive plots, statistics, trails and measurements. **New 3D assembly** starts a model from scratch.
- **Readable mechanisms.** Joint symbols at their anchors and axes, coil and strut symbols for force elements and frame triads, drawn over the CAD; hover highlighting between the 3D view and the model tree.
- **Guided tour.** Walks through building the wheel-end drop test across the three workspaces, with buttons that start the assembly, load the STEP parts and open the finished study.
- **Post-processing.** Hover readouts, click-to-scrub plots, channel min/max/RMS, body-axes angular velocity, motion trails, follow camera, frame stepping, speed control and a presentation mode.
- **Constraint diagnostics.** A rank analysis reports the true mobility and names redundant joint constraints before MBDyn rejects an over-constrained loop.
- **AI assistant.** Proposals list each edit in engineering terms before you apply them; a configurable time budget supports CPU-only local models.
- **Desktop on every platform.** Native host for Linux (WebKitGTK), macOS and Windows. The Linux build bundles MBDyn 1.7.3 and works without configuration.

### Downloads
| File | Notes |
| --- | --- |
| `Kinemeld-0.2.0-linux-x86_64.tar.gz` | Bundled MBDyn. Needs Python 3.10+ and `libwebkit2gtk-4.1-0`. Run `./kinemeld`. |
| `Kinemeld-0.2.0-macos-arm64.zip` | Apple silicon. Bundles MBDyn when the macOS solver build succeeded (see `package-manifest.json` → `bundledSolver`). Needs Python 3.10+. Not notarized: Control-click → Open. |
| `Kinemeld-0.2.0-windows-x86_64.zip` | Needs Python 3.10+, WebView2 and an MBDyn configured through WSL (`docs/solver.md`). |
| `mbdyn-1.7.3.tar.gz` | Corresponding source for the bundled GPL-2.0-only MBDyn binaries. |

STEP import in any package: `python3 -m pip install -r requirements.txt` (installs `cadquery-ocp` 7.9).

See `CHANGELOG.md` for the full list of changes. Kinemeld is a preview: its studies are teaching models, not validated hardware.
