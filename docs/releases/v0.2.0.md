Kinemeld 0.2.0 reorganises the workbench into **Pre-processing → Solve → Post-processing** workspaces, adds six featured MBDyn studies with physics verification, and ships desktop builds for Linux, macOS and Windows.

### Highlights
- **Professional workflow.** Each workspace shows only what that stage needs: model tree and properties; study settings, pre-run checks and a solver console; or animation, interactive plots, statistics, trails and measurements.
- **Post-processing.** Hover readouts, click-to-scrub plots, channel min/max/RMS, body-axes angular velocity, motion trails, follow camera, frame stepping, speed control and a presentation mode.
- **Featured studies.** Quarter-car suspension, oleo-pneumatic drop test, slider-crank run-up, gyroscopic top, tumbling T-handle and chaotic double pendulums — each one click from *Examples*, each checked against independent physics.
- **Desktop on every platform.** Native host for Linux (WebKitGTK), macOS and Windows. The Linux build bundles MBDyn 1.7.3 and works without configuration.

### Downloads
| File | Notes |
| --- | --- |
| `Kinemeld-0.2.0-linux-x86_64.tar.gz` | Bundled MBDyn. Needs Python 3.10+ and `libwebkit2gtk-4.1-0`. Run `./kinemeld`. |
| `Kinemeld-0.2.0-macos-arm64.zip` | Apple silicon. Bundles MBDyn when the macOS solver build succeeded (see `package-manifest.json` → `bundledSolver`). Needs Python 3.10+. Not notarized: Control-click → Open. |
| `Kinemeld-0.2.0-windows-x86_64.zip` | Needs Python 3.10+, WebView2 and an MBDyn configured through WSL (`docs/solver.md`). |
| `mbdyn-1.7.3.tar.gz` | Corresponding source for the bundled GPL-2.0-only MBDyn binaries. |

STEP import in any package: `python3 -m pip install -r requirements.txt` (installs `cadquery-ocp` 7.9).

See `CHANGELOG.md` for the full list of changes. Kinemeld is a preview: its studies are teaching models, not validated hardware.
