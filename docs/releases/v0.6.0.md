Kinemeld 0.6.0 is about trust: your work survives a crash, STEP works with the current OpenCascade, and every download is tested on a clean machine before it is published.

### Highlights
- **Crash-safe autosave.** The desktop app keeps a recovery snapshot of unsaved work, written atomically once editing pauses. After an unexpected exit, Kinemeld offers it back as an unsaved project; Save suggests the original file instead of overwriting it.
- **OpenCascade 8.** STEP import, face picking and mass properties work with `cadquery-ocp` 8 as well as 7.9.
- **Clean-machine release checks.** Each archive is unpacked on fresh Linux, macOS and Windows runners: every file against its manifest hash, the packaged service with an empty user folder, real MBDyn solves, and the desktop self-check. A release is published only when all of them pass.

See `native/README.md` (Autosave and crash recovery, Checking a release package) and `CHANGELOG.md`.
