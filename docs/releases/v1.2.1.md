Kinemeld 1.2.1: a documentation update to 1.2.0.

- The in-app help no longer refers to a separate project for finite-element analysis.
- Documentation and code comments describe CAD behaviour without naming other products.
- The macOS package is now built and checked on macOS 15 (Apple silicon), as GitHub retires its macOS 14 build machines.

Features and projects are unchanged from 1.2.0; see `CHANGELOG.md` and the [1.2.0 notes](https://github.com/AkshayRamanandaRao/Kinemeld/releases/tag/v1.2.0).
