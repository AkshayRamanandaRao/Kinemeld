Kinemeld 1.0.0: every download is self-contained.

### Highlights
- **Windows works out of the box.** The Windows package now includes MBDyn 1.7.3, built in CI with Cygwin, so no WSL or separate solver installation is needed. The Linux and macOS bundles have run on clean machines since 0.6.
- **Checked before publishing.** Each archive — Linux, macOS and Windows — is unpacked on a fresh machine, checked file by file, and solves real models before the release is published.
- **Your projects are safe across 1.x.** Every 1.x release opens projects saved by earlier 1.x releases and by 0.2–0.9; see `docs/project-format.md`.

Since 0.2: workspaces for pre-processing, solving and post-processing; verified featured studies; rotary drives; full-resolution results and run comparison; joints placed from CAD faces and hole rims; crash-safe autosave; parameter studies. See `CHANGELOG.md`.
