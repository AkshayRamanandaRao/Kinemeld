Kinemeld 0.4.0 makes post-processing quantitative.

### Highlights
- **Full-resolution results.** Plots, readouts and statistics use every MBDyn step, not just the 2,000 displayed samples. Peak-preserving decimation keeps one-step spikes visible; the statistics panel reports the peak time and time-weighted RMS.
- **Pinned traces.** Overlay the same quantity for several bodies or elements — for example both chaotic pendulums, or all three robot-arm motor torques.
- **Compare runs.** Pin a solution, change a parameter, run again and read both responses on one plot.
- **Export.** Download any plot as SVG or PNG.

See `docs/workspaces.md` (Post-processing) and `CHANGELOG.md`.
