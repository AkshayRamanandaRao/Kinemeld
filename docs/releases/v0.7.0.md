Kinemeld 0.7.0 adds parameter studies: ask "what if" of any physical input and see every answer on one plot.

### Highlights
- **Sweep one input.** Choose a stiffness, damping, mass, strut setting, drive setting or initial velocity, give a list of values (half to double the current one by default), and MBDyn solves every case. The current value is always included as the baseline.
- **Compare at a glance.** All cases of the chosen response are drawn together, ordered from blue to orange, with a table of peaks (and when they occur), RMS and final values that exports to CSV.
- **Animate any case.** Select a row to play that case in the 3D view; saved projects keep the baseline result.

For example, sweeping the wheel-end drop's tyre contact stiffness from 10 to 40 kN/m raises the peak contact force from about 620 N to 1,290 N. See `docs/workspaces.md` (Parameter studies, Study results) and `CHANGELOG.md`.
