# Original 3D wishbone example

Open `wishbone.mbdyn-studio` from Kinemeld. The project embeds the three original STEP sources and their bindings; the standalone `.step` files are provided for inspection or reuse. See [the worked guide](../../docs/wishbone-3d.md) for dimensions, materials, operation and independent reference checks. These illustrative assets are MIT licensed and are not a production vehicle design.
